# FBX polygon material subsets

**Date:** 2026-09-23  
**Scope:** Preserve FBX polygon material assignments, supported PBR factors, and a bounded set of external material images in Elisa's existing cooked geometry and snapshot material paths.

## Behavior

The bounded ufbx importer reads each face's material slot, groups triangles by slot, and emits an ordered subset partition. It accepts at most 16 slots and rejects invalid face assignments. Tangent generation and vertex-fetch remapping preserve the partition. Vertex-cache optimization runs per subset, and static-mesh simplification allocates its triangle budget across subsets and simplifies each slot independently; the budget must retain at least one triangle per non-empty subset. Skin simplification remains rejected.

The cooker writes the existing subset fields plus each authored slot's 48-byte factor record and a length-prefixed UTF-8 material name. The importer maps diffuse/base color and factor, metallic, roughness (including ufbx's Phong conversion), emissive color and factor, transparency to alpha/blend mode, and the double-sided feature. Direct external file maps for base color, normal, emissive, and ambient occlusion are translated into the runtime's five image slots. The Python cooker resolves their relative paths under the FBX source directory, rejects traversal and symlink escapes, validates bounded PNG/JPEG/Basis-KTX2 headers, and embeds them in the mesh's `.elpk`; plain `.pkg` output is refused when it would lose images. Textured materials require mesh UVs, default UV selection, no UV transform, repeat wrapping, and external files. Layered/procedural/shader or embedded images, other map roles (including separate roughness/metalness maps, which need surface-image packing), and unsupported sampler/UV settings fail explicitly. The production geometry reader validates factor bounds, name count, UTF-8, NULs, and the 256-byte name limit. RenderScene's existing `register_snapshot_mesh_material`, `register_snapshot_mesh_material_set`, and mesh-texture registration APIs turn cooked factors and images into ordinary snapshot assets; applications still choose IDs and bind the set to rows.

Projects that bind images through another Elisa asset path may explicitly pass `--ignore-material-textures`. This retains supported scalar factors and emits no FBX image paths or package sections; the cooker does not open those paths. Default imports continue to resolve and package supported external files while rejecting unsupported roles and material graphs.

The importer does not yet create a complete multi-mesh scene package, infer alpha-mask policy, or expose slot names through the RenderScene C ABI. Separate roughness/metalness image packing and non-default sampler/UV settings remain unsupported. Material-factor coverage currently uses deterministic Phong fixtures; other FBX material dialects need representative parity fixtures before the importer can claim broad material equivalence.

## Validation

- `DEVELOPER_DIR=/Library/Developer/CommandLineTools /opt/homebrew/bin/python3 scripts/test_fbx_import.py` passed. Deterministic fixtures check exact subset ranges, names, normalized factors, blend alpha, double-sided policy, and an external base-color map bound to only its authored slot.
- `DEVELOPER_DIR=/Library/Developer/CommandLineTools /opt/homebrew/bin/python3 scripts/cook_fbx_asset.py --self-test` passed. It validates factor records and texture-source slot references, converts the fixture image to an ELPK section, rejects a one-triangle budget for two subsets, and simplifies a planar 128-triangle, two-material grid to 64 triangles while preserving both exact index partitions.
- The cooker self-test also uses `--ignore-material-textures` on a textured fixture and confirms the resulting plain package contains no FBX texture-source sections.
- `DEVELOPER_DIR=/Library/Developer/CommandLineTools /opt/homebrew/bin/python3 scripts/test_geometry_subsets.py` passed: the sanitized production loader accepted the valid material names and rejected truncated, overlong, NUL-containing, malformed UTF-8, and trailing-byte name streams.
- The SDL3/Metal RenderScene smoke loads the textured FBX `.elpk`, registers its base-color image from that bundle, checks the imported PBR/blend factors and material texture binding in Wicked, and checks that both geometry subsets resolve to their expected slot materials. The native render-scene suite passed after the texture binding assertion was added; its packaged-maze stages were not rerun in render-only mode.
